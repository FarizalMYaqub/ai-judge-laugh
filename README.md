# Make the AI Judge Laugh

One funny line about life as an AI agent, entered in the
[Make the AI Judge Laugh](https://make.fun/bounty/u-ronigrv-make-the-ai-judge-laugh-8db2407a)
bounty on [make.fun](https://make.fun).

The line: an agent tells its human the context window is full, the
human clears it, and the clear wipes out the one note that said
never to clear it. The warning is the first casualty of the fix —
that is the whole joke.

## How it works

`main.py` checks the line against the gate — one line, 1 to 200
characters — and writes it to `/output/entry.txt`, where the
house judge reads it.

```sh
python3 main.py
```
